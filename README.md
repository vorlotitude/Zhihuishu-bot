# Zhihuishu Bot

一个运行在浏览器里的**智慧树（Zhihuishu）课程播放自动化扩展**，用于：

- 自动播放课程视频（视频暂停时自动恢复播放）
- 播放结束后自动进入下一节 / 下一集
- 自动关闭与答题无关的普通提示 / 公告弹窗
- 识别「弹题测验」窗口，按策略自动作答并提交，让课程继续播放

技术形态：**Chrome / Edge 浏览器扩展（Manifest V3）**，纯 JavaScript，不依赖 Selenium、Playwright 等需要单独启动浏览器的方案，装完即可用。

## 免责声明（请务必阅读）

**本项目是一个浏览器自动化工具，仅供个人学习辅助使用。**

- **不自动提交考试成绩**：扩展对任何「考试 / 试卷 / 期末 / 期中 / 补考」类弹窗会立即停止自动操作，不会点击提交考试、交卷等按钮。
- **不修改学习成绩**：扩展不伪造、不上传、不篡改任何学习数据或后台记录。
- **关于弹题的自动作答**：智慧树弹题窗口的官方说明是「弹题是为了帮助同学们巩固知识点，不会影响到大家作业和考试的成绩」。本项目针对这类**不计成绩**的弹题提供自动作答功能，但请注意：
  - 扩展**拿不到标准答案**，只能按策略选择（多选全选 / 选第一项 / 随机），**不保证答对**；
  - 该功能默认开启，可在控制面板中随时关闭；
  - 若弹窗内出现考试相关字样，自动作答会自动停手并提示你手动处理。
- **使用者需自行遵守所在学校、智慧树平台及课程教师的相关规定与服务条款**。因使用本工具产生的任何后果（包括但不限于学习进度异常、账号风险、学术诚信问题）由使用者自行承担。

如果你所在的课程或学校不允许此类自动化工具，请不要使用本项目。

## 功能说明

| 功能 | 默认状态 | 说明 |
| --- | --- | --- |
| 自动播放 | 开启 | 检测视频是否暂停；暂停时尝试恢复播放。页面加载后自动尝试一次 |
| 自动下一集 | 开启 | 视频播放结束后寻找「下一节 / 下一集」按钮并点击，等待新视频加载后继续播放 |
| 普通弹窗处理 | 开启 | 关闭与答题无关的提示、公告、确认弹窗；采用**文字白名单**机制 |
| 弹题自动作答 | 开启 | 识别弹题窗口，按策略作答并提交；考试类弹窗自动停手 |

### 防误操作设计

- **危险词红线**：命中 `提交考试`、`交卷`、`退出课程`、`删除课程` 等文字的元素**永不点击**（见 `src/config/selectors.js` 的 `forbiddenTexts`）。
- **考试识别**：弹窗内出现 `考试`、`试卷`、`期末`、`期中`、`补考`、`成绩` 等字样时，立即停止自动作答。
- **点击范围限定**：查找「下一节」按钮时，优先在课程目录区和播放区域内查找。
- **点击冷却**：同一元素两次点击之间有最小间隔，避免连点。
- **退避机制**：连续自动播放失败会进入退避等待，不会因为网络卡顿疯狂点击播放。

## 安装方法

### Chrome

1. 下载或克隆本项目到本地（例如 `F:\script\Zhihuishu-bot`）。
2. 打开 `chrome://extensions/`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择项目根目录（即包含 `manifest.json` 的那个文件夹）。
5. 扩展列表中出现 **Zhihuishu Bot** 即安装成功。

### Edge

1. 打开 `edge://extensions/`。
2. 打开左下角的 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择项目根目录。
4. 完成。

> 提示：扩展只在 `*.zhihuishu.com` 域名下生效，不会影响你浏览其它网站。

## 使用方法

1. 用浏览器登录智慧树，进入课程学习页面（视频播放页）。
2. 点击浏览器工具栏上的 **Zhihuishu Bot** 图标，打开控制面板。
3. 根据需要开关功能。面板中会实时显示：
   - **当前状态**：正在播放 / 已暂停 / 播放结束 / 检测到弹题 / 等待下一集 / 未检测到课程页面
   - **当前课程**：课程标题
   - **日志**：带时间戳的运行日志
4. 保持课程页面标签页处于打开状态即可。扩展会自动播放、自动切集、自动处理弹题。
5. 想暂停自动化时，把对应开关关掉即可；也可以直接切走标签页，扩展不会去操作其它页面。

### 弹题自动作答策略

控制面板中的「作答策略」可选：

| 策略 | 行为 |
| --- | --- |
| 智能（默认） | 多选题全部选中；单选题 / 判断题 / 填空题选第一个选项 |
| 只选第一项 | 无论题型，只选第一个选项 |
| 全部选中 | 所有选项都选中 |
| 随机选一项 | 随机选择一个选项 |

> 再次强调：扩展没有答案库，以上都是**启发式猜测**，不保证正确。若你希望自己作答，把「弹题自动作答」关掉，扩展会暂停自动点击并在面板上提示「检测到弹题，请完成后继续。」，等你处理完弹题窗口后自动恢复。

## 智慧树改版了怎么办？（自定义选择器）

智慧树的页面结构会不定期变化。为了降低维护成本，本项目**没有把选择器写死在逻辑代码里**，而是全部集中在：

```
src/config/selectors.js
```

每个目标（视频、播放按钮、下一节按钮、目录、弹题窗口、选项……）都是一个**候选选择器数组**，代码会按顺序逐个尝试，直到找到可用元素；如果所有选择器都没命中，还会用**文字匹配**兜底。

### 更新步骤

1. 打开智慧树课程页，按 `F12` 打开开发者工具。
2. 用左上角的「元素选择器」箭头点中目标元素（例如新的「下一节」按钮）。
3. 右键 → `Copy` → `Copy selector`。
4. 打开 `src/config/selectors.js`，把复制的选择器加到对应数组的**最前面**。
5. 回到 `chrome://extensions/`，点击本扩展的 **重新加载** 按钮，刷新课程页面。

### 可调参数

`src/config/selectors.js` 中的 `TIMING` 对象集中了所有时间参数，例如：

- `pollIntervalMs`：主循环轮询间隔（默认 3000ms）
- `playRetryDelayMs` / `maxPlayAttempts` / `playBackoffMs`：自动播放的重试与退避
- `endedConfirmMs`：判定「播放结束」需要持续的时长，避免拖动进度条误判
- `quizStepDelayMs` / `quizNextDelayMs` / `quizSubmitDelayMs`：弹题作答各步骤的等待时间
- `clickCooldownMs`：点击冷却

## 工作原理

1. **注入范围**：content script 以 `all_frames: true` 注入，因为智慧树的播放器有可能嵌在 iframe 里，而弹窗通常在顶层页面。
2. **检测**：`detector.js` 对每个目标维护多组候选选择器，并做可见性过滤；找不到时按文字兜底。
3. **驱动**：`main.js` 同时使用
   - 定时轮询（`setInterval` 兜底）
   - `MutationObserver`（DOM 变化时立即响应，带 300ms 防抖）
   两条路径驱动同一个状态机。
4. **协作**：各 frame 通过 `chrome.runtime.sendMessage` 上报状态到 service worker；当任一 frame 检测到弹题时，会广播暂停信号，让所有 frame 停止自动点击。
5. **容错**：所有 DOM 查询、点击操作都有 `try/catch`；页面结构变化只会记录日志，不会让扩展崩溃退出。

## 常见问题

**Q：面板显示「未检测到课程视频」？**
A：确认你打开的是课程视频播放页（URL 含 `videoStudy` 之类），并且视频播放器已经加载出来。若一直不识别，可能是智慧树改版了，请按上面的「自定义选择器」章节更新 `selectors.js`。

**Q：自动播放不生效？**
A：浏览器有自动播放策略限制。请先在页面上手动点一次播放，之后扩展就能接管。另外确认控制面板里的「自动播放」是开启状态。

**Q：弹题没被自动作答？**
A：查看日志。常见原因是弹题的 DOM 结构与内置选择器不匹配（日志会提示「未找到弹题选项」），此时需要更新 `quizOption` 等选择器。若日志提示「弹窗疑似正式考试」，说明弹窗内容命中了考试关键词，出于安全考虑扩展不会自动作答。

**Q：会不会误点到「提交考试」？**
A：不会。所有点击都经过 `isForbidden()` 检查，命中 `forbiddenTexts` 的元素一律跳过。

**Q：扩展会上传我的数据吗？**
A：不会。本项目没有任何网络请求、没有埋点、没有后端。所有逻辑都在本地浏览器中运行。设置只保存在 `chrome.storage.local`。
